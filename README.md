# Grocery Store Sales Analysis

## Project Overview

This project analyzes grocery store sales data using SQL Server to identify key sales trends, product performance, outlet performance, and other business insights.

The analysis focuses on creating SQL queries for important KPIs and business requirements that support data-driven decision-making.

## Tools & Technologies

- SQL Server
- SQL Server Management Studio (SSMS)

## Key KPIs

- Total Sales
- Average Sales
- Total Number of Records
- Sales by Item Fat Content
- Sales by Item Type
- Sales by Outlet
- Sales by Location
- Sales by Outlet Size
- Customer/Product Ratings

## Analysis Performed

The SQL analysis includes:

- Total sales calculation
- Average sales calculation
- Sales segmentation by item fat content
- Sales analysis by item type
- Outlet-level sales analysis
- Location-based sales analysis

## Project Files

- Grocery_Store_Sales_Analysis.sql — SQL queries used for the analysis
- SQL screenshots — Supporting screenshots of the analysis and queries
- README.md — Project documentation

## Project Skills Demonstrated

- Aggregate Functions
- GROUP BY
- WHERE
- COUNT
- SUM
- AVG
- CAST
- CONCAT
- Conditional Filtering

## Business Objective
The objective of this project is to use SQL to transform raw grocery store data into meaningful business insights that help understand sales performance, product trends, outlet performance, and customer ratings.
